# US003-7 — QR e número da guia

Lista e detalhe usam o número oficial da guia que vem da API (ex.: `2026-000003`).
O QR é desenhado com o código de `GET /atendimentos/{id}/qrcode`, sem gerar
códigos no frontend. Sessões incompletas, procedimentos realizados ou faturados
e guias expiradas não oferecem QR. Quem decide é o backend: resposta de erro ou
sem código nunca mostra imagem, ampliação ou download.

## Teste local

Depende do backend rodando com o perfil `dev` (seed de teste).

```sh
npm ci
npm run dev
```

No `.env` do front, `VITE_API_URL=http://localhost:8080`.

1. Abra `http://localhost:5173/login` e entre como beneficiário (CPF da lista de
   usuários de teste da tela de login, senha `fusex123`).
2. Em **Minhas guias**, abra uma guia com procedimento cuja última sessão já foi
   registrada pela OCS: o QR aparece; amplie e baixe o PNG.
3. Procedimentos com sessões faltando, realizados ou de guia expirada não mostram QR.
4. No detalhe, **Baixar PDF da guia** baixa o documento guardado na emissão, e o
   histórico da guia aparece abaixo dos procedimentos.
